# Telegram Voice Transcriber Bot

Этот Telegram-бот предназначен для автоматического преобразования голосовых сообщений и аудиофайлов в текст. Он использует библиотеку `python-telegram-bot` для взаимодействия с Telegram и Google Speech Recognition для распознавания речи.


## Текущие возможности

  * **Расшифровка аудио:** Автоматическое распознавание речи при отправке голосового сообщения или аудиофайла боту.
  * **Поддерживаемые форматы:** OGG (для голосовых сообщений), MP3, M4A, WAV (для аудиофайлов).
  * **Многоформатная обработка:** Используется `pydub` для преобразования аудио в формат WAV, необходимый для библиотеки `SpeechRecognition`.
  * **Уведомления:** Пользователь получает сообщения о начале обработки и о результатах распознавания.

## Планы развития

Мы планируем расширить функционал бота следующими ключевыми возможностями:

  * **Интерактивный интерфейс:** Внедрение кнопок и меню для выбора действий ("Расшифровать", "Пересказать").
  * **Саммаризация (Пересказ):** Добавление функции получения краткого изложения сути длинного голосового сообщения или аудиозаписи.
  * **Конспектирование:** Специализированный режим для обработки длинных аудиозаписей (например, лекций или совещаний) с целью создания структурированных конспектов.

## Установка и запуск

### Предварительные требования

Для работы бота необходимо:

  * Установленный **Python 3.8+**.
  * **FFmpeg:** Это системная библиотека, необходимая для `pydub` для обработки аудиоформатов (MP3, M4A и т.д.). Установите её для вашей операционной системы (например, через `apt install ffmpeg` в Debian/Ubuntu или `brew install ffmpeg` в macOS).

### Установка зависимостей Python

Создайте виртуальное окружение и установите необходимые пакеты, указанные в файле `requirements.txt`:

```bash
python -m venv venv
source venv/bin/activate # Для Linux/macOS
# или venv\Scripts\activate # Для Windows

pip install -r requirements.txt
```

### Настройка токена

Получите токен для вашего бота через **BotFather** в Telegram.

Рекомендуется использовать переменную окружения для хранения токена. Создайте файл `.env` в корне проекта или экспортируйте переменную в терминале:

```
# В .env файле
BOT_TOKEN=ВАШ_ТОКЕН_БОТА
```

Если вы используете переменные окружения, замените строку с токеном в файле `bot.py` на чтение из окружения. Для этого вам также понадобится библиотека `python-dotenv`:

```python
import os
from dotenv import load_dotenv

load_dotenv() 
BOT_TOKEN = os.getenv('BOT_TOKEN')
```

*Примечание: Если токен остается в коде, не публикуйте его в открытом доступе.*

### Запуск

Запустите основной файл:

```bash
python bot.py
```

## Технические детали

  * **Библиотеки:** `python-telegram-bot`, `SpeechRecognition`, `pydub`.
  * **Распознавание:** Используется `recognize_google` (API Google Web Speech), что обеспечивает высокое качество распознавания на русском языке (`LANG_CODE = "ru-RU"`).
  * **Обработка файлов:** Загруженный файл временно сохраняется на диск, конвертируется в WAV с помощью `pydub`, распознается, а затем временные файлы (`.ogg`/.`mp3` и `.wav`) удаляются для очистки рабочей директории.
